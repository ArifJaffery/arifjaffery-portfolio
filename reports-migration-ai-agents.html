Ten years of inspection reports, moved by AI agents

A property inspection business sold its building and strata reports through a WordPress shop that had been running since 2016. We built three small AI agents to lift every report, product page and PDF off that site into an organised archive, ready for the next system.

What we're trying to achieve

The old shop stores each property as an address page that sells one or more reports, such as a Building & Pest report or a Strata report. Behind each report sits a PDF in a protected folder on the web server. None of it can move to a new system until it's out, organised and accounted for.

  • Get every PDF off the server, safelyCopy all 5,502 report PDFs over SFTP, keeping the original year and month folders, without changing anything on the live site.
  • Capture every product and its pageRead all 5,468 products from WooCommerce and save each public page as it looks today.
  • Link products to their PDFsKnow exactly which PDF each report delivers, and flag the ones that are missing or stored elsewhere.
  • Leave a manifest the next tools can trustTwo JSON manifests record every file and product, with empty fields ready for the CRM: OpportunityId, OrderId and whether each one has been processed.
  • Survive interruptionsRuns take hours, so every agent can be stopped with Q and resumed later without redoing work.

Architecture

Each agent is a short Python program. You chat with it in a terminal; OpenAI's model decides which tool to call; the tools do the real work against the server and the website and write everything to your PC. Anything long-running asks you to confirm first.

The loop

LangGraph's StateGraph alternates between the model and the tools until the model has an answer. tools_condition decides which way to go; MemorySaver keeps the conversation, so follow-ups like "and the archive folder?" work.

The model

gpt-4.1-mini at temperature 0 turns plain requests into tool calls with the right folder path. A system prompt keeps it honest: only report what tools return, and never ask for passwords.

The tools

Plain Python functions with clear docstrings, which become the tool descriptions the model reads. They do the heavy lifting, ask you to confirm in the terminal, and write manifests atomically after each step.

The agents we built

Each one grew out of the one before it, using the same chat loop and adding tools.

@contextmanager
def sftp_session():
    """Open an SFTP (SSH) session, as most desktop SFTP clients do."""
    import paramiko

    if not FTP_HOST:
        raise RuntimeError("FTP_HOST is not set in .env")

    ssh = paramiko.SSHClient()
    # Note: accepts the server's host key on first use. For production,
    # load known hosts instead: ssh.load_system_host_keys()
    ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    ssh.connect(
        FTP_HOST,
        port=FTP_PORT,
        username=FTP_USER,
        password=FTP_PASSWORD,
        timeout=15,
        allow_agent=False,
        look_for_keys=False,
    )
    try:
        sftp = ssh.open_sftp()
        try:
            yield sftp
        finally:
            sftp.close()
    finally:
        ssh.close()


def connect_ftp():
    """Open an authenticated FTP (or FTPS) connection."""
    if not FTP_HOST:
        raise RuntimeError("FTP_HOST is not set in .env")

    ftp = FTP_TLS() if FTP_USE_TLS else FTP()
    ftp.connect(FTP_HOST, FTP_PORT, timeout=15)
    ftp.login(FTP_USER, FTP_PASSWORD)
    if FTP_USE_TLS:
        ftp.prot_p()  # encrypt the data channel too
    return ftp


# ---------- Helpers ----------

def resolve_remote_dir(sftp, path: str) -> tuple[str, str]:
    """Find a folder on the SFTP server. Returns (absolute_path, home_folder).

    Over SFTP, "/" is the server's root, not your hosting folder (unlike FTP).
    So "/public_html/x" and "public_html/x" are both looked up inside the home
    folder first, then as a real absolute path (e.g. "/home/user/public_html").
    """
    home = sftp.normalize(".")
    path = (path or "").strip() or "."
    candidates = [posixpath.normpath(posixpath.join(home, path.lstrip("/")))]
    if path.startswith("/"):
        candidates.append(posixpath.normpath(path))

    for candidate in candidates:
        try:
            if stat.S_ISDIR(sftp.stat(candidate).st_mode or 0):
                return candidate, home
        except OSError:
            continue
    raise FileNotFoundError(
        f"Folder not found: '{path}' (looked inside the home folder {home} "
        f"and at the server root)"
    )


def home_relative(abs_path: str, home: str) -> str:
    """'/home/user/public_html/x' -> '/public_html/x' (paths outside home unchanged)."""
    home = home.rstrip("/")
    if abs_path == home:
        return "/"
    if abs_path.startswith(home + "/"):
        return abs_path[len(home):]
    return abs_path


def list_sftp(path: str) -> list[str]:
    with sftp_session() as sftp:
        path, _ = resolve_remote_dir(sftp, path)
        lines = []
        for entry in sftp.listdir_attr(path):
            if stat.S_ISDIR(entry.st_mode or 0):
                lines.append(f"[DIR]  {entry.filename}")
            else:
                lines.append(f"[FILE] {entry.filename} ({entry.st_size} bytes)")
        return lines


def list_ftp(path: str) -> list[str]:
    with connect_ftp() as ftp:
        lines = []
        try:
            # MLSD gives type and size; not every server supports it
            for name, facts in ftp.mlsd(path, facts=["type", "size"]):
                if name in (".", ".."):
                    continue
                if facts.get("type") == "dir":
                    lines.append(f"[DIR]  {name}")
                else:
                    lines.append(f"[FILE] {name} ({facts.get('size', '?')} bytes)")
        except error_perm:
            lines = list(ftp.nlst(path))  # fallback for servers without MLSD
        return lines


def walk_sftp(sftp, remote_dir: str, extension: str):
    """Yield (remote_path, size) for every matching file under remote_dir."""
    for entry in sftp.listdir_attr(remote_dir):
        remote_path = posixpath.join(remote_dir, entry.filename)
        mode = entry.st_mode or 0
        if stat.S_ISLNK(mode):
            continue  # skip symlinks to avoid loops
        if stat.S_ISDIR(mode):
            yield from walk_sftp(sftp, remote_path, extension)
        elif entry.filename.lower().endswith(extension):
            yield remote_path, entry.st_size or 0


def local_path_for(remote_path: str) -> Path:
    """Map a remote path to the same structure under DOWNLOAD_DIR."""
    parts = [p for p in remote_path.split("/") if p]
    if any(p in (".", "..") for p in parts):
        raise ValueError(f"Unsafe remote path: {remote_path}")
    target = DOWNLOAD_DIR.joinpath(*parts).resolve()
    if DOWNLOAD_DIR not in target.parents:
        raise ValueError(f"Path escapes download folder: {remote_path}")
    return target


def manifest_location(remote_dir: str, remote_path: str) -> tuple[str, str]:
    """Return (FolderName, FileName), FolderName relative to the source folder."""
    rel = posixpath.relpath(remote_path, remote_dir)
    return posixpath.dirname(rel) or ROOT_FOLDER, posixpath.basename(rel)


def human_size(n: float) -> str:
    for unit in ("B", "KB", "MB", "GB"):
        if n < 1024:
            return f"{n:.1f} {unit}"
        n /= 1024
    return f"{n:.1f} TB"


def stop_requested() -> bool:
    """True if the user pressed Ctrl+C, or typed Q, since the last check."""
    if CANCEL.is_set():
        return True
    try:
        if os.name == "nt":
            import msvcrt
            while msvcrt.kbhit():
                if msvcrt.getwch().lower() == "q":
                    return True
        else:
            import select
            if select.select([sys.stdin], [], [], 0)[0]:
                if sys.stdin.readline().strip().lower() == "q":
                    return True
    except Exception:
        pass  # no interactive console; rely on Ctrl+C only
    return False


# ---------- Tools the agent can call ----------

@tool
def list_ftp_files(path: str = "/") -> str:
    """List files and folders in a directory on the FTP server.

    Args:
        path: Directory path on the server, e.g. "/" or "/reports/2026".
    """
    try:
        lines = list_sftp(path) if FTP_PROTOCOL == "sftp" else list_ftp(path)
        if not lines:
            return f"No files found in '{path}'."

        total = len(lines)
        lines = sorted(lines)[:MAX_ENTRIES]
        result = f"Contents of '{path}' ({total} items):\n" + "\n".join(lines)
        if total > MAX_ENTRIES:
            result += f"\n...and {total - MAX_ENTRIES} more not shown."
        return result
    except Exception as error:
        return f"FTP error while listing '{path}': {error}"


@tool
def migrate_files(remote_dir: str, extension: str = ".pdf") -> str:
    """Migrate (copy) all files with a given extension from a server folder,
    including every subfolder, to the local download folder with the same
    folder structure, and record each file in the JSON migration manifest.

    The migration can be stopped at any time and resumed by calling this tool
    again with the same folder: files already migrated are skipped.
    The user confirms in the terminal before anything is copied.

    Args:
        remote_dir: Folder on the server, e.g. "/public_html/wp-content/uploads/woocommerce_uploads".
        extension: File extension to migrate, e.g. ".pdf". Case-insensitive.
    """
    if FTP_PROTOCOL != "sftp":
        return "migrate_files currently supports SFTP only (set FTP_PROTOCOL=sftp)."

    extension = extension.lower()
    if not extension.startswith("."):
        extension = "." + extension

    CANCEL.clear()
    MIGRATION_RUNNING.set()
    temp = None
    manifest = None
    try:
        with sftp_session() as sftp:
            # 1. Find the folder ("/public_html/x" and "public_html/x" both work)
            try:
                abs_dir, home = resolve_remote_dir(sftp, remote_dir)
            except FileNotFoundError as error:
                return str(error)
            source_folder = home_relative(abs_dir, home)  # e.g. "/public_html/..."

            # 2. Load the manifest from the last run, or start a new one
            try:
                if MANIFEST_PATH.exists():
                    manifest = Manifest.load(MANIFEST_PATH)
                    previous = manifest.source_folder
                    try:
                        previous = home_relative(resolve_remote_dir(sftp, previous)[0], home)
                    except FileNotFoundError:
                        pass
                    if previous != source_folder:
                        return (f"The manifest at {MANIFEST_PATH} belongs to a migration "
                                f"of '{manifest.source_folder}', not '{source_folder}'. "
                                f"Set a different MANIFEST_PATH in .env to migrate "
                                f"another folder.")
                    manifest.data["SourceFolder"] = source_folder
                else:
                    manifest = Manifest.create(MANIFEST_PATH, source_folder, DOWNLOAD_DIR)
            except json.JSONDecodeError as error:
                return (f"The manifest at {MANIFEST_PATH} is not valid JSON ({error}). "
                        f"Fix or move it first.")

            # 3. Scan the server and compare with what's already migrated
            print(f"\nScanning {source_folder} for {extension} files...")
            found = sorted(walk_sftp(sftp, abs_dir, extension))
            if not found:
                return f"No {extension} files found under '{source_folder}'."

            pending, already_done = [], 0
            for remote_path, size in found:
                folder, name = manifest_location(abs_dir, remote_path)
                local = local_path_for(home_relative(remote_path, home))
                if local.exists() and local.stat().st_size == size:
                    # Downloaded before (maybe before the manifest existed):
                    # make sure it's recorded, without resetting other fields
                    manifest.add_file(folder, name, size)
                    already_done += 1
                else:
                    pending.append((remote_path, local, folder, name, size))

            manifest.data["TotalFilesFound"] = len(found)
            if not pending:
                manifest.data["Status"] = "Completed"
                manifest.save()
                return (f"Migration complete: all {len(found)} {extension} files are "
                        f"migrated. Manifest: {MANIFEST_PATH} "
                        f"(ReportCounts = {manifest.data['ReportCounts']}).")

            manifest.data["Status"] = "InProgress"
            manifest.save()

            # 4. Confirm with the human directly, so the model can't skip it
            total_bytes = sum(p[4] for p in pending)
            if already_done:
                print(f"Resuming: {already_done} of {len(found)} files already migrated.")
            print(f"Ready to copy {len(pending)} files ({human_size(total_bytes)}) "
                  f"to {DOWNLOAD_DIR}")
            if input("Proceed? (y/n): ").strip().lower() not in ("y", "yes"):
                manifest.data["Status"] = "Paused"
                manifest.save()
                return "The user cancelled before copying. Nothing new was copied."

            print("Press Q (or Ctrl+C) at any time to stop. "
                  "Progress is saved after every file.\n")

            # 5. Copy one file at a time, saving the manifest after each
            copied, failed, stopped = 0, [], False
            for i, (remote_path, local, folder, name, size) in enumerate(pending, 1):
                if stop_requested():
                    stopped = True
                    break
                try:
                    local.parent.mkdir(parents=True, exist_ok=True)
                    temp = local.with_name(local.name + ".part")
                    sftp.get(remote_path, str(temp))
                    temp.replace(local)
                    temp = None
                    manifest.add_file(folder, name, size)
                    manifest.save()
                    copied += 1
                    print(f"  [{already_done + copied}/{len(found)}] {folder}/{name}")
                except Exception as error:
                    failed.append(f"{remote_path}: {error}")
                    if temp is not None:
                        temp.unlink(missing_ok=True)
                        temp = None

        migrated = manifest.data["ReportCounts"]
        if stopped:
            manifest.data["Status"] = "Paused"
            result = (f"Migration stopped by the user. {migrated} of {len(found)} files "
                      f"are migrated ({copied} this run). Ask to migrate the same "
                      f"folder again to resume.")
        elif failed:
            manifest.data["Status"] = "Paused"
            result = (f"Copied {copied} files; {len(failed)} failed and will be retried "
                      f"next run. {migrated} of {len(found)} files are migrated.\n"
                      + "\n".join(failed[:20]))
            if len(failed) > 20:
                result += f"\n...and {len(failed) - 20} more."
        else:
            manifest.data["Status"] = "Completed"
            result = (f"Migration complete: copied {copied} files this run, "
                      f"{migrated} of {len(found)} migrated in total.")
        manifest.save()
        return result + f"\nManifest: {MANIFEST_PATH}"

    except Exception as error:
        if manifest is not None:
            try:
                manifest.data["Status"] = "Paused"
                manifest.save()
            except Exception:
                pass
        return (f"Error while migrating '{remote_dir}': {error}. Progress so far is "
                f"saved; run the migration again to resume.")
    finally:
        if temp is not None:
            temp.unlink(missing_ok=True)
        MIGRATION_RUNNING.clear()

"""Read and write the migration manifest (JSON).

Used by the migration agent, and can be imported by the other tools that
later update ReportType, FileProcessed, OpportunityId and OrderId.

Example (from another tool):

    from migration_manifest import Manifest, REPORT_TYPE_BUILD

    m = Manifest.load("downloads/migration_manifest.json")
    m.update_file("2024/03", "report.pdf",
                  ReportType=REPORT_TYPE_BUILD,
                  FileProcessed="Yes",
                  OpportunityId="3f2c9a1e-....",
                  OrderId="9b1d77c4-....")
    m.save()
"""

import json
import os
import time
from datetime import datetime
from pathlib import Path

# ReportType values
REPORT_TYPE_UNKNOWN = 0
REPORT_TYPE_BUILD = 1
REPORT_TYPE_STRATA = 2

ROOT_FOLDER = "."  # FolderName used for files directly in the source folder

# Fields other tools are allowed to change
UPDATABLE_FIELDS = {"ReportType", "FileProcessed", "OpportunityId", "OrderId"}


def new_file_entry(file_name: str, size: int) -> dict:
    return {
        "FileName": file_name,
        "Size": size,
        "ReportType": REPORT_TYPE_UNKNOWN,
        "FileProcessed": "No",
        "OpportunityId": "",
        "OrderId": "",
    }


class Manifest:
    def __init__(self, path, data: dict):
        self.path = Path(path)
        self.data = data
        self._folders = {}  # FolderName -> folder dict
        self._files = {}    # (FolderName, FileName) -> file dict
        for folder in data.setdefault("Folders", []):
            self._folders[folder["FolderName"]] = folder
            for entry in folder.setdefault("Files", []):
                self._files[(folder["FolderName"], entry["FileName"])] = entry

    # ---------- create / load / save ----------

    @classmethod
    def load(cls, path) -> "Manifest":
        path = Path(path)
        return cls(path, json.loads(path.read_text(encoding="utf-8")))

    @classmethod
    def create(cls, path, source_folder: str, local_folder) -> "Manifest":
        now = datetime.now()
        data = {
            "Date": now.strftime("%Y-%m-%d"),
            "Time": now.strftime("%I:%M %p"),   # e.g. "04:38 PM"
            "ReportCounts": 0,
            "Status": "InProgress",             # InProgress / Paused / Completed
            "SourceFolder": source_folder,
            "LocalFolder": str(local_folder),
            "Folders": [],
        }
        return cls(path, data)

    def save(self) -> None:
        """Write atomically, so a crash or Ctrl+C never leaves a broken file."""
        self.data["ReportCounts"] = len(self._files)
        self.data["Folders"].sort(key=lambda f: f["FolderName"])
        for folder in self.data["Folders"]:
            folder["Files"].sort(key=lambda f: f["FileName"].lower())

        self.path.parent.mkdir(parents=True, exist_ok=True)
        temp = self.path.with_name(self.path.name + ".tmp")
        temp.write_text(json.dumps(self.data, indent=2), encoding="utf-8")

        # Windows can briefly lock the file (antivirus, an editor) - retry
        for attempt in range(10):
            try:
                os.replace(temp, self.path)
                return
            except PermissionError:
                if attempt == 9:
                    raise
                time.sleep(0.5)

    # ---------- file entries ----------

    @property
    def source_folder(self) -> str:
        return self.data.get("SourceFolder", "")

    def get(self, folder_name: str, file_name: str):
        return self._files.get((folder_name, file_name))

def get_with_retry(client: httpx.Client, url: str, **kwargs) -> httpx.Response:
    """GET with retries for network errors and busy-server responses."""
    for attempt in range(5):
        try:
            response = client.get(url, **kwargs)
        except httpx.TransportError:
            if attempt == 4:
                raise
            time.sleep(2 ** attempt)
            continue
        if response.status_code in (429, 500, 502, 503, 504) and attempt < 4:
            retry_after = response.headers.get("Retry-After", "")
            time.sleep(int(retry_after) if retry_after.isdigit() else 2 ** attempt)
            continue
        return response
    return response

def is_json(response: httpx.Response) -> bool:
    return "json" in response.headers.get("content-type", "")


class WooApi:
    """Read-only WooCommerce REST API client that finds the right API address."""

    def __init__(self, client: httpx.Client):
        self.client = client
        self.base = None  # (style, version) once found
        # Some hosts strip the Authorization header; then we send the keys
        # as query parameters instead (still encrypted, as the site uses HTTPS)
        self.query_auth = False

    def _url(self, style: str, version: str, path: str, params: dict):
        if style == "wp-json":
            return f"{SITE_URL}/wp-json/wc/{version}/{path}", dict(params)
        return f"{SITE_URL}/", {"rest_route": f"/wc/{version}/{path}", **params}

    def _raw(self, style: str, version: str, path: str, params: dict) -> httpx.Response:
        url, query = self._url(style, version, path, params)
        if not self.query_auth:
            response = get_with_retry(self.client, url, params=query,
                                      auth=(WC_KEY, WC_SECRET))
            if response.status_code != 401:
                return response
            self.query_auth = True
        return get_with_retry(self.client, url, params={
            **query, "consumer_key": WC_KEY, "consumer_secret": WC_SECRET})

    def get(self, path: str, params: dict) -> httpx.Response:
        if self.base is None:
            tried = []
            for style, version in API_CANDIDATES:
                response = self._raw(style, version, path, params)
                label = (f"/wp-json/wc/{version}/" if style == "wp-json"
                         else f"/?rest_route=/wc/{version}/")
                # 404, or a normal web page instead of data = not here
                if response.status_code == 404 or (response.status_code == 200
                                                   and not is_json(response)):
                    tried.append(f"{label} -> HTTP {response.status_code}"
                                 + ("" if is_json(response) else " (web page)"))
                    continue
                self.base = (style, version)
                print(f"Using WooCommerce API at {label}")
                return self._check(response)
            raise RuntimeError(
                "Could not find the WooCommerce API. Tried:\n  " + "\n  ".join(tried) +
                f"\nOpen {SITE_URL}/wp-json/ in a browser: if it shows an error or the "
                f"home page, the REST API is disabled (often by a security plugin).")
        return self._check(self._raw(*self.base, path, params))

    def _check(self, response: httpx.Response) -> httpx.Response:
        if response.status_code in (401, 403):
            detail = ""
            if is_json(response):
                detail = f" ({response.json().get('message', '')})"
            raise RuntimeError(
                f"The WooCommerce API refused access, HTTP {response.status_code}{detail}. "
                f"Check WC_CONSUMER_KEY / WC_CONSUMER_SECRET in .env and that the key has "
                f"Read permission.")
        response.raise_for_status()
        if not is_json(response):
            raise RuntimeError(
                "The API returned a web page instead of data; a security plugin or "
                "firewall may be blocking API requests.")
        return response


def pdf_location(file_url: str):

def layout(index: dict):
    """Group products the way the manifest shows them:
    [(address_page, [reports...]), ...] plus reports with no address page."""
    by_name = lambda e: e["Name"].lower()
    def primary_parent(e):
        return next((p for p in e["ParentIds"]
                     if p in index and index[p]["Type"] == "grouped"), None)

    reports = [e for e in index.values() if e["Type"] != "grouped"]
    groups = []
    for g in sorted((e for e in index.values() if e["Type"] == "grouped"), key=by_name):
        children = [e for e in reports if primary_parent(e) == g["Id"]]
        groups.append((g, sorted(children, key=by_name)))
    unlinked = sorted((e for e in reports if primary_parent(e) is None), key=by_name)
    return groups, unlinked


def assign_packages(index: dict) -> None:
    """Decide each product's package folder and its PDFs' local names."""
    groups, unlinked = layout(index)
    placed = [(g, g["Id"], None) for g, _ in groups]
    placed += [(c, g["Id"], g["Id"]) for g, kids in groups for c in kids]
    placed += [(e, 0, 0) for e in unlinked]
    for entry, property_id, parent in placed:
        entry["PackageFolder"] = (f"packages/{property_id}" if parent is None
                                  else f"packages/{parent}/{entry['Id']}")
        used = set()
        for f in entry["Files"]:
            if not site_file_path(f["Url"]):
                f["LocalFile"] = ""  # external link (e.g. a file-sharing service): not downloaded
                continue
            raw = posixpath.basename(unquote(urlparse(f["Url"]).path)) or "file.pdf"
            name = safe_file_name(raw)
            stem, ext = os.path.splitext(name)
            n = 1
            while name.lower() in used:  # two PDFs with the same name
                n += 1
                name = f"{stem}-{n}{ext}"
            used.add(name.lower())
            f["LocalFile"] = f"{entry['PackageFolder']}/{name}"

def package_entry(entry: dict, client: httpx.Client, fetcher) -> list[str]:
    """Do everything for one product: page HTML, data JSON, PDFs.
    Returns a list of problems (empty if all went well)."""
    problems = []
    folder = PRODUCTS_DIR / entry["PackageFolder"]
    folder.mkdir(parents=True, exist_ok=True)
    pid = entry["Id"]

    # 1. Page HTML (kept in html\ too, so it's only downloaded once)
    if entry["HtmlFile"]:
        cache = PRODUCTS_DIR / entry["HtmlFile"]
        if not cache.exists():
            response = get_with_retry(client, entry["Permalink"])
            if response.status_code == 200:
                cache.parent.mkdir(parents=True, exist_ok=True)
                temp = cache.with_name(cache.name + ".part")
                temp.write_bytes(response.content)
                os.replace(temp, cache)
            else:
                problems.append(f"page HTTP {response.status_code}")
            time.sleep(PAGE_DELAY)
        entry["HtmlSaved"] = cache.exists()
        if cache.exists():
            copy_atomic(cache, folder / f"{pid}.html")

    # 2. Product data JSON
    copy_atomic(PRODUCTS_DIR / entry["DataFile"], folder / f"{pid}.json")

    # 3. Report PDFs: copied from the PDF migration if there, else via SFTP
    for f in entry["Files"]:
        if f["Downloaded"] in ("Yes", "External"):
            continue
        if stop_requested():
            update_packaged(entry)
            raise StopRequested()
        site_path = site_file_path(f["Url"])
        target = PRODUCTS_DIR / f["LocalFile"]
        try:
            local = local_pdf_copy(site_path)
            if local:
                copy_atomic(local, target)
            else:
                fetcher.download(site_path, target)
            f["Downloaded"] = "Yes"
        except FileNotFoundError:
            f["Downloaded"] = "Missing"
            problems.append(f"not on server: {site_path}")
        except Exception as error:
            problems.append(f"{posixpath.basename(site_path)}: {error}")

    update_packaged(entry)
    return problems


def render_manifest(meta: dict, index: dict, migrated) -> dict:
    """Build the nested Properties -> Reports manifest from the flat index."""
    def yes_no(flag):

            "Slug": e["Slug"],
            "Status": e["Status"],
            "Permalink": e["Permalink"],
            "Price": e["Price"],
            "DateCreated": e["DateCreated"],

        return obj

    groups, unlinked = layout(index)
    properties = []
    for g, children in groups:

            "ProductId": g["Id"],

        "PartialCounts": sum(1 for r in reports if r["Packaged"] == "Partial"),

        "Site": SITE_URL,
        "LocalFolder": str(PRODUCTS_DIR),

        include_pages_and_files: False to only refresh product data and the
            manifest, without downloading pages or PDFs.
    """

        return ("WC_CONSUMER_KEY and WC_CONSUMER_SECRET are not set in .env. Create a "
                "read-only key in WordPress: WooCommerce > Settings > Advanced > REST API.")

    CANCEL.clear()
    MIGRATION_RUNNING.set()
    manifest, index, data_complete = None, {}, False
    fetcher = SftpFetcher()
    try:
        (date, time_), preserved = load_previous()
        manifest = {"Date": date, "Time": time_, "Status": "InProgress",
                    "_migrated": load_migrated_pdfs()}
        (PRODUCTS_DIR / "data").mkdir(parents=True, exist_ok=True)
        (PRODUCTS_DIR / "html").mkdir(parents=True, exist_ok=True)

        with make_client() as client:
            # ---- Phase 1: product data from the API (quick; always refreshed) ----
            api = WooApi(client)
            print(f"\nFetching product data from {SITE_URL} ...")
            page, seen = 1, set()
            while True:
                if stop_requested():
                    # Don't overwrite the manifest with a partial product list
                    return ("Stopped by the user while reading product data. "
                            "Run again to resume.")
                response = api.get("products", {
                    "per_page": 100, "page": page, "status": "any",
                    "orderby": "id", "order": "asc"})
                items = response.json()
                total_pages = int(response.headers.get("X-WP-TotalPages") or 1)
                for product in items:
                    save_json_atomic(PRODUCTS_DIR / "data" / f"{product['id']}.json", product)
                    index[product["id"]] = manifest_entry(product, preserved.get(product["id"]))
                    seen.add(product["id"])
                print(f"  page {page}/{total_pages}: {len(seen)} products")
                if not items or page >= total_pages:
                    break
                page += 1

            # Link address pages (grouped) <-> report products
            for entry in index.values():
                entry["ParentIds"] = []
            for entry in index.values():
                for child_id in entry["ChildIds"]:
                    if child_id in index:
                        index[child_id]["ParentIds"].append(entry["Id"])
            # Older WooCommerce: children point at their grouped parent instead
            for entry in index.values():
                parent_id = entry.get("ApiParentId") or 0
                parent = index.get(parent_id)
                if parent and parent["Type"] == "grouped":
                    if parent_id not in entry["ParentIds"]:
                        entry["ParentIds"].append(parent_id)
                    if entry["Id"] not in parent["ChildIds"]:
                        parent["ChildIds"].append(entry["Id"])

            # Work out what earlier runs already finished, from the files on disk
            for entry in index.values():
                entry["HtmlSaved"] = bool(entry["HtmlFile"]) and \
                    (PRODUCTS_DIR / entry["HtmlFile"]).exists()
            assign_packages(index)
            refresh_package_state(index)
            data_complete = True
            save_manifest(manifest, index)

            if not include_pages_and_files:
                return (f"Saved data for {len(seen)} products and rebuilt the manifest. "
                        f"Manifest: {MANIFEST_PATH}")

            # ---- Phase 2: product by product: page, data, PDFs -> package ----
            groups, unlinked = layout(index)
            order = [e for g, kids in groups for e in (g, *kids)] + list(unlinked)
            pending = [e for e in order if e["Packaged"] == "No"]
            done_before = len(order) - len(pending)

            if not pending:
                manifest["Status"] = "Completed"
                save_manifest(manifest, index)
                return (f"Complete: all {len(order)} products are packaged "
                        f"({manifest['PartialCounts']} reports have external or missing "
                        f"PDFs). Manifest: {MANIFEST_PATH}")

            pages = sum(1 for e in pending if e["HtmlFile"]
                        and not (PRODUCTS_DIR / e["HtmlFile"]).exists())
            pdfs = [f for e in pending for f in e["Files"] if f["Downloaded"] == "No"]
            local = sum(1 for f in pdfs if local_pdf_copy(site_file_path(f["Url"])))
            minutes = pages * (PAGE_DELAY + 1) / 60 + (len(pdfs) - local) * 3 / 60
            if done_before:
                print(f"Resuming: {done_before} of {len(order)} products already done.")
            print(f"Ready to process {len(pending)} products: {pages} pages to download, "
                  f"{len(pdfs)} PDFs ({local} copied from the PDF migration, "
                  f"{len(pdfs) - local} via SFTP). Roughly {minutes:.0f} minutes.")
            print(f"Package folders: {PRODUCTS_DIR / 'packages'}")
            if input("Proceed? (y/n): ").strip().lower() not in ("y", "yes"):
                manifest["Status"] = "Paused"
                save_manifest(manifest, index)
                return ("Product data and the manifest are saved; the user cancelled "
                        "before pages and PDFs. Run again to continue.")

            print("Press Q (or Ctrl+C) at any time to stop. Progress is kept.\n")
            processed, failed, stopped = 0, [], False
            for i, entry in enumerate(pending, 1):
                if stop_requested():
                    stopped = True
                    break
                try:
                    problems = package_entry(entry, client, fetcher)
                except StopRequested:
                    stopped = True
                    break
                except Exception as error:
                    problems = [str(error)]
                processed += 1
                kind = "Address" if entry["Type"] == "grouped" else "Report "
                print(f"  [{done_before + i}/{len(order)}] {kind} {entry['Id']}: "
                      f"{entry['Name'][:70]} -> {entry['Packaged']}")
                if problems:
                    failed.append(f"{entry['Id']} {entry['Name'][:60]}: {'; '.join(problems)}")
                if i % SAVE_EVERY == 0:
                    save_manifest(manifest, index)

        incomplete = sum(1 for e in order if e["Packaged"] == "No")
        manifest["Status"] = "Completed" if not stopped and incomplete == 0 else "Paused"
        save_manifest(manifest, index)

        summary = (f"{manifest['PackagedCounts']} reports fully packaged, "
                   f"{manifest['PartialCounts']} partial (external or missing PDFs), "
                   f"{incomplete} products not finished.")
        if stopped:
            result = f"Stopped by the user after {processed} products this run. {summary} Run again to resume."
        else:
            result = f"Processed {processed} products this run. {summary}"
        if failed:
            result += f"\n{len(failed)} products had problems (retried next run):\n" + \
                      "\n".join(failed[:20])
            if len(failed) > 20:
                result += f"\n...and {len(failed) - 20} more."
        return result + f"\nManifest: {MANIFEST_PATH}"

    except Exception as error:
        if manifest is not None and data_complete:
            try:
                manifest["Status"] = "Paused"
                save_manifest(manifest, index)
            except Exception:
                pass
        return f"Error while downloading products: {error}. Progress is saved; run again to resume."
    finally:
        fetcher.close()
        MIGRATION_RUNNING.clear()

def find_products(search: str = "", limit: int = 40) -> str:
    """Search the downloaded products (local manifest) by words in the product
    name/address, or by product ID. With an empty search, returns a summary.

    Args:
        search: Words to match, e.g. "12 Sample Street strata", or a product ID.
        limit: Maximum number of lines to return.
    """
    if not MANIFEST_PATH.exists():
        return "No products downloaded yet. Use download_products first."
    manifest = json.loads(MANIFEST_PATH.read_text(encoding="utf-8"))
    if "Properties" not in manifest:
        return "The manifest is in the old format. Run download_products to rebuild it."
    properties = manifest["Properties"]
    reports = [(p, r) for p in properties for r in p["Reports"]]
    type_names = {0: "Unknown", 1: "Build", 2: "Strata"}

    if not search.strip():
        by_type = {}
        for _, r in reports:
            label = type_names.get(r["ReportType"], str(r["ReportType"]))
            by_type[label] = by_type.get(label, 0) + 1
        files = [f for _, r in reports for f in r["Files"]]
        no_pdf = sum(1 for _, r in reports if not r["Files"])
        not_migrated = sum(1 for f in files if f["Migrated"] == "No")
        unlinked = next((len(p["Reports"]) for p in properties if p["ProductId"] == 0), 0)
        return (f"Manifest from {manifest['Date']} {manifest['Time']}, status {manifest['Status']}.\n"
                f"Address pages: {manifest['PropertyCounts']}; reports: {manifest['ReportCounts']} "
                f"({unlinked} with no address page); HTML pages saved: {manifest['HtmlCounts']}.\n"
                f"Report types: {by_type}\n"
                f"Reports packaged: {manifest.get('PackagedCounts', 0)} fully, "
                f"{manifest.get('PartialCounts', 0)} partially (external or missing PDFs)\n"
                f"Reports with no PDF: {no_pdf}; PDFs linked: {len(files)}; "
                f"linked PDFs missing from the PDF migration: {not_migrated}")

    term = search.strip()
    if term.isdigit():
        pid = int(term)
        prop_hits = [p for p in properties if p["ProductId"] == pid and pid != 0]
        report_hits = [(p, r) for p, r in reports if r["ProductId"] == pid]
    else:
        words = term.lower().split()
        match = lambda text: all(w in text.lower() for w in words)
        prop_hits = [p for p in properties if p["ProductId"] != 0 and match(p["Name"])]
        report_hits = [(p, r) for p, r in reports
                       if match(r["Name"]) and p not in prop_hits]

    lines = []
    for p in prop_hits:
        lines.append(f"- Address page ID {p['ProductId']}: {p['Name']} "
                     f"({len(p['Reports'])} reports, HTML saved: {p['HtmlSaved']})")
        for r in p["Reports"]:
            lines.append("    " + describe_report(r, type_names))
    for p, r in report_hits:
        where = f"address page ID {p['ProductId']}" if p["ProductId"] else "no address page"
        lines.append(f"- {describe_report(r, type_names)} [{where}]")

    if not lines:
        return f"No products match '{search}'."
    more = f"\n...({len(lines) - limit} more lines not shown)" if len(lines) > limit else ""
    return f"Matches for '{search}':\n" + "\n".join(lines[:limit]) + more

            f"packaged: {r.get('Packaged', '-')} | processed: {r['ProductProcessed']}")

"""SFTP helper used by the product agent to download website files.

Uses the same .env settings as ftp_agent.py (FTP_HOST, FTP_PORT, FTP_USER,
FTP_PASSWORD). Keeps one connection open and reconnects if it drops.
"""

import os
import posixpath
import time
from pathlib import Path


class SftpFetcher:
    def __init__(self):
        self.host = os.getenv("FTP_HOST")
        self.port = int(os.getenv("FTP_PORT", "22"))
        self.user = os.getenv("FTP_USER", "")
        self.password = os.getenv("FTP_PASSWORD", "")
        # Folder on the server that holds the website (wp-content lives inside it)
        self.web_root = os.getenv("SERVER_WEB_ROOT", "public_html")
        self.ssh = None
        self.sftp = None
        self.home = ""

    def _connect(self):
        import paramiko

        if not self.host:
            raise RuntimeError("FTP_HOST is not set in .env (needed to download PDFs over SFTP)")
        self.close()
        ssh = paramiko.SSHClient()
        # Note: accepts the server's host key on first use. For production,
        # load known hosts instead: ssh.load_system_host_keys()
        ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
        ssh.connect(self.host, port=self.port, username=self.user, password=self.password,
                    timeout=15, allow_agent=False, look_for_keys=False)
        self.ssh = ssh
        self.sftp = ssh.open_sftp()
        self.home = self.sftp.normalize(".")

    def close(self):
        for conn in (self.sftp, self.ssh):
            try:
                if conn is not None:
                    conn.close()
            except Exception:
                pass
        self.sftp = self.ssh = None

    def remote_path(self, site_path: str) -> str:
        """'/wp-content/uploads/x.pdf' -> '/home/<user>/public_html/wp-content/uploads/x.pdf'"""
        return posixpath.join(self.home, self.web_root, site_path.lstrip("/"))

    def download(self, site_path: str, target: Path) -> None:
        """Download a website file to target. Raises FileNotFoundError if it
        isn't on the server. Writes to a .part file first, so an interrupted
        download never looks complete."""
        target.parent.mkdir(parents=True, exist_ok=True)
        temp = target.with_name(target.name + ".part")
        for attempt in range(2):
            try:
                if self.sftp is None:
                    self._connect()
                self.sftp.get(self.remote_path(site_path), str(temp))
                os.replace(temp, target)
                return
            except FileNotFoundError:
                temp.unlink(missing_ok=True)
                raise
            except Exception:
                temp.unlink(missing_ok=True)
                if attempt == 1:
                    raise
                self.close()  # connection may have dropped: reconnect once
                time.sleep(2)

How we got here

Problems we hit and how each one was solved, in order. Yellow marks a fix that changed the code.

  1. 26 October

    The chat forgot every message

    History was stored but never sent back, and thread_id did nothing without a checkpointer. Adding MemorySaver fixed it.

  2. 26 October

    An FTP tool for the agent

    Added list_ftp_files and the agent and tools loop, with credentials kept in .env and out of the conversation.

  3. 26 October

    "530 Login authentication failed"

    A debug test script showed the server's exact replies. The username had the server address attached, then turned out to be missing its final letter, which we spotted in a screenshot from a desktop SFTP client.

  4. 26 October

    The server wanted SFTP, not FTP

    The desktop SFTP client was connecting over SSH on port 22. The agent gained an SFTP mode using paramiko, chosen with FTP_PROTOCOL=sftp.

  5. 26 October

    Copying PDFs with the folder structure

    Added a recursive download tool with a terminal confirmation that the model can't skip.

  6. 27 October

    A manifest, and a way to stop and resume

    Built migration_manifest.py, saved after every file, and stopping with Q or Ctrl+C, which works even though LangGraph runs tools in a background thread.

  7. 27 October

    "Folder does not exist"

    Over SFTP, / is the whole server, not your hosting folder. Paths are now looked up inside the home folder first, so both forms work.

  8. 27 October

    "No module named paramiko"

    Installed into a different Python. Running the same way you install (uv add with uv run) fixed it.

  9. 27 October

    5,502 files, 37.5 GB

    Checked disk space, sleep settings and git before saying yes. The run survived an accidental window close and resumed from the manifest.

  10. 28 October

    Product agent, and an API that wasn't there

    WooCommerce returned 404 for API version 3. The key's "last access" time proved authentication worked, so the agent now finds the version the site actually has.

  11. 28 October

    Product manifest shaped like the PDF manifest

    Address pages became the folders and reports became the files, each linked to its PDFs and checked against the PDF migration.

  12. 28 October

    A package folder per product

    After each product's page downloads, its data, page and PDFs are gathered into one folder, with PDFs over SFTP.

  13. 28 October

    Pages looked unstyled when opened locally

    The HTML was complete. Its links start with //, which means "https" on the web but "file" on a PC.

  14. 28 October

    The run seemed to freeze

    Clicking in a Windows terminal turns on "Select" mode, which pauses the program. Press Esc, or turn off QuickEdit.
