Security hardening case study

Hardening a public WordPress server, from the edge gateway down to the config file

A single internet-facing Windows VM running WordPress on IIS. I reviewed it layer by layer, closed remote-admin exposure, and locked down the host, the web server and the application without taking the site offline.

The work

Controls by layer

Each control lists what changed, why it matters, and the command or setting behind it. Select a layer, then open any item.

    Web server

    The site's web.config, before and after

    The original file only handled WordPress permalinks. The hardened version blocks direct requests for sensitive files, stops the server advertising its PHP version, and adds browser protections. The permalink rule is unchanged.

    Request filtering added

    + <directoryBrowse enabled="false" />
+ <security>
+   <requestFiltering removeServerHeader="true">
+     <hiddenSegments>
+       <add segment="wp-config.php" />
+       <add segment="xmlrpc.php" />
+       <add segment="debug.log" />
+     </hiddenSegments>
+   </requestFiltering>
+ </security>

    Next phase

    Recommended next, in priority order

    Hardening is not finished after one pass. These items were scoped during the review and are planned as the follow-up phase.

    • Priority 1

      HTTPS and modern TLS

      Point a domain at the server, issue a Let's Encrypt certificate with win-acme, redirect HTTP to HTTPS, and disable TLS 1.0 and 1.1.

    • Priority 2

      Rotate keys and salts

      Replace the eight WordPress authentication keys, which invalidates every existing session cookie.

    • Priority 3

      Admin login protection

      Two-factor authentication for administrator accounts and a limit on failed login attempts.

    • Priority 4

      Off-server backups

      Scheduled copies of site files and database stored away from the host, with one tested restore.

    • Priority 5

      Enforce rate limits

      Review the log-only data from Dynamic IP Restrictions, tune the thresholds, then switch to blocking.
